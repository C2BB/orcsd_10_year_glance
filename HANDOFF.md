## What this is
Independent dashboard "Ten years at a glance" for the Oyster River Cooperative School District (ORCSD, SAU #5; towns Durham, Lee, Madbury), FY 2017-18 to FY 2026-27. It is not an official publication. **Fiscal-year key everywhere = the year the school year ends** (FY2018 = 2017-18); the DOE's own year labels follow the same rule. In `data/orcsd_years.json` the `fy` field is the label ("2017-18"); scripts use `int(fy[:4]) + 1`.

- Public page: https://c2bb.github.io/orcsd_10_year_glance/ (GitHub Pages, branch `main`, `index.html` + `app.js` + `data/`). Single-file copy with data inlined: `dist/ORCSD_Ten_Years_at_a_Glance.html`.
- Private hosted copy: a Claude artifact (see "Hosted copy"). Optional; the repo is the source of truth.
- Maintainer: Colin (ORCSD parent). Commit author used so far: `C2B2 <advacomp@gmail.com>`.

## State
- 68 rows in 9 sections (spending, cost per student, where the money goes, who pays, town shares, students, results, climate and safety, more detail). Every value comes from `data/orcsd_years.json` (one object per FY under `rows`, plus `meta` documenting each field); per-row, per-year source links come from `data/sources.json`.
- Features: year picker; change since FY18 per row; per-year source links; inflation switch (as recorded, CPI-U, ECI) with a top card, sticky control and a tag on every dollar row; deep links to sections, rows and notes (`#ela`, `#who-pays`, `#notes-attendance`; a "Jump to" bar; the link icon copies the URL); a "repo copy" link per source that opens the mirrored file.
- Every number on the page traces to a file in `raw/` (see "Raw sources"). Checked values: 466 school-level cells and 126 ESSA ratings vs raw dashboard exports; town equalized value and ADM vs the DOE CSVs; special-education aid and EFA counts vs DOE files; Durham/Lee/Madbury tax rates vs DRA workbooks; NH truancy, NH state shares, administrator pay and salary schedules vs the DOE files. All of these checks pass (commands below).
- Inflation switch: dollar fields listed in `MONEY` in `build/page.js` are multiplied by the year's index. Rows with `money: true` adjust in chart and label; rows in `CHIP_B` chart a share or rate but their hover dollars adjust (`tipMoney`); `base` (property value per student) and `rate` (tax rate per $1,000) are deliberately not adjusted and say so.

## Reaching the sources (access recipes and traps)
- **education.nh.gov and revenue.nh.gov block cloud fetch and plain curl (Akamai 403).** Only a real browser session works. In the Claude desktop in-app browser, open a tab on the site, then use same-origin `fetch()` to read pages (a BFS over same-origin links lists every file) and hash files; download with an anchor click (`a.download = name`), about 11 s apart. Downloads land in `~/Downloads` as hidden temp files `.Q6L2SF6YDW.com.anthropic.claudefordesktop.*`; match them to names by **size + SHA-256 prefix** with a map file of `sha8 size raw-name` lines and a small script that copies matches into `raw/<name>`, then run `python3 build/add_manifest.py <map>`. Raw naming: `nh-doe/` or `nh-dra/` + the path after the last `/files/` with `/` replaced by `__`.
- **NH DOE dashboards are Tableau.** Entry points are under https://www.education.nh.gov/who-we-are/division-of-educator-and-analytic-resources/iplatform and open as `https://jwt.nh.gov/?src_route=<view>&debug_session=false&toolbar=Hidden&Width=1300px&Height=1600px` with `<view>` = `/iExplore/Explore-Dashboard`, `iReport/FrontPage`, `iAchieve/AssessmentParticipation`, `iGrant-FinancialTransparencyfromNHSchoolsDistricts/iGrantsHome`, `iGlossary/Glossary` (they embed dashboards.nh.gov/t/sonhpublic). The old `dashboard.nh.gov` links are dead.
- **iExplore.** In the page, `document.querySelector('tableau-viz').workbook` is the Embedding API. Entity names are exact (`Oyster River Coop (District)`, `Oyster River High School`, `Oyster River Middle School`, `Mast Way School`, `Moharimet School`, `State of New Hampshire`). On the Compare dashboard worksheet `*Download Compare` returns Category, Indicator Name, Year ID, entity, value; set all four entity parameters (`Compare: Entity A`, `A Download`, `B`, `B Download`) or other entities come back. `await workbook.changeParameterValueAsync('Year ID Param', Y)`, wait about 3.5 s, `getSummaryDataAsync({maxRows:5000, ignoreSelection:true})`; each call returns a three-year window ending at Y, so Y = 2018, 2021, 2024, 2026 covers 2016 to 2026. About 35 district indicators exist (growth, participation, proficiency, graduation, dropout, post-secondary, staffing, finance shares, enrollment, class size, discipline, counselor ratio). **The State of New Hampshire column is wrong for graduation, post-secondary and participation** (graduation about 36%, enrollment a single school): never draw an NH line from it without checking.
- **iReport** (`iReport/FrontPage`): set `Search for School or District Name (Master)` = `Oyster River Coop (District)` and `Select Year` (2018 to 2026; 2017 errors), activate `ESSA Profiles (District)`, read worksheets `SE - In School`, `SE - Out of School`, `SE - Expusions` (row "All Students") for suspension and expulsion rates; IDEA indicator 5 (row `incl`; FY19 and FY20 repeat the prior year in the DOE file, so FY19 is blank). The ESSA rating sheets return only links for districts; ratings come from the iExplore export.
- **iPlatform report viewer hangs, its data endpoint works** from a my.doe.nh.gov tab: `fetch('/iPlatform/Report/ViewReportPage/?reportPath=<path>&page=N&ReportID=<id>&SchoolYear=<Y>')` (30 to 60 s per page; SchoolYear 2026 = 2025-26). ReportIDs: District Fall Enrollment 4, ADM in Attendance and Residence 3, Town Level Enrollment By Grade 12 (path `/BDMQ/iPlatform Reports/Enrollment Data/Enrollments by Grade/Town Level Enrollment By Grade`, 8 pages per year), Teacher Salary Schedule 22, attendance by district 29 (returns NaN for 2023 to 2025, retired), completers by status by school 33, average class size 36, FTE Staff by District 38, Teacher Attainment 40, attendance by school 74. These reports offer no download, so their values are transcriptions in `raw/nh-doe/iplatform-extracts-2026-11-22.md` and `raw/nh-doe/extracts-2026-11-22/`.
- **iGrant** (federal grants, Tableau): ESSER Relief and FY23 IDEA/Preschool sources; Oyster River shows $0 for every funding type (about 30 of 654 entities show any amount), so nothing to chart; federal aid comes from DOE-25.
- **DOE finance and staffing files** are plain downloads linked from the Bureau of School Finance pages: DOE-25 (`raw/nh-doe25/`), valuation and tax-rate files, adequacy-aid municipal summaries, equalized valuation per pupil CSVs (`equal_pupil*`, `eqprt*`, `EVPP*`), special-education allocation CSVs, EFA-by-municipality workbooks, salary and FTE reports, school safety workbooks, restraint and seclusion reports, state summary files, College Board SAT reports. The DOE site lists about 3,370 files; those not mirrored are other districts' data, pre-2016 duplicates or forms.
- **DRA files** (https://www.revenue.nh.gov/about-dra/municipal-and-property-division/municipal-and-property-reports): tax-rate calculation workbooks, municipal-and-village tax rate sheets, equalization surveys and ratio studies, state education tax warrants, county apportionments, cooperative school district apportionments (`<tax year>-cooperative-school-district-apportionments.pdf`; file year N is the sheet for FY N+1, so the 2025 file is FY2026; the 2021 to 2023 files are scanned images, read by rendering pages). Some PDFs can only be fetched from inside the user's browser session.
- **Relay lesson:** moving files from the browser to the Mac by base64 pieces needs a CRC32 per piece and a final SHA-256 of the decoded file; hash match is the real check.

## Conventions
**Source rule (decided by the maintainer, 2026-11-23): state first.** Where the district and the NH DOE/DRA print different numbers for the same measure, the page shows the state's and the district's stays in `CONFLICTS.md`; where two state series disagree, use the DOE's headline district figure (enrollment: iExplore `Total Enrollment`, district entity, all years, so FY2019/FY2020/FY2026 are 2,190/2,202/2,064, not the report's 2,157/2,168/2,038, which equal the sum of the DOE's four schools). District figures are used where the state has no series.
