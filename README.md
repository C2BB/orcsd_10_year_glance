# ORCSD "Ten years at a glance"

Independent school-finance and outcomes dashboard for the Oyster River Cooperative School District (Durham, Lee, Madbury), FY 2017-18 to FY 2026-27, built from public NH DOE, NH DRA, BLS and ORCSD records. Not an official publication of the district or the state.

Live page: https://c2bb.github.io/orcsd_10_year_glance/

Picking this up (person or AI assistant)? Read [`HANDOFF.md`](HANDOFF.md) first: current state, rebuild and check commands, how to reach the state sites (the DOE's Tableau dashboards, blocked downloads), the hosted-copy limits, and open items.

## Layout

| Path | What it is |
|---|---|
| `index.html`, `app.js` | The page. Loads `data/*.json` at runtime, then draws. Generated by `build/`. |
| `data/orcsd_years.json` | One row per fiscal year with every value the page shows, plus `meta` documenting each field. |
| `data/sources.json` | Per-row, per-year links to the original file or section page. |
| `dist/ORCSD_Ten_Years_at_a_Glance.html` | Same page as one file with the data inlined; works from disk or as an attachment. |
| `raw/` | Copies of the source files the values were taken from, by origin: `nh-doe/`, `nh-doe25/`, `nh-dra/`, `bls/`, `orcsd/`. `raw/MANIFEST.csv` gives each file's original URL, retrieval date, size and SHA-256 and says which row uses it; `raw/TRACE.md` maps every page source and row to its files. |
| `build/` | Scripts that regenerate `data/` and the page from the typed-in values (`rc_data.py`, `towns_data.py`, `nhdoe_values.py`, `doe25.py`), the checks (`verify_*.py`), and `build/tests/` (Playwright). |
| `CONFLICTS.md`, `data/conflicts.csv` | Where district-printed figures and state figures disagree, with the file and page of both numbers (generated by `build/conflicts.py`). |
| `HANDOFF.md` | Current-state notes for whoever continues the work. |

## Rebuilding and checking

```
cd build
python3 make_data.py     # -> orcsd_years.json
python3 build_pages.py   # -> ../index.html, ../app.js, ../data/, ../dist/
cd .. && python3 build/verify_raw.py   # manifest and checksums for raw/
```

Fiscal-year key = year the school year ends (FY 2018 = 2017-18). Many values were read by hand from PDFs (annual reports, DOE PDFs); they are keyed in `build/rc_data.py` and `build/towns_data.py` with comments naming the source file, and the `verify_*.py` scripts compare them with the machine-readable originals wherever those exist. `HANDOFF.md` lists every check.

To preview locally: `python3 -m http.server` in the repo root and open http://localhost:8000/ (browsers block `fetch` on `file://`, which is why `dist/` exists).

## Caveats

Some figures are estimates or computed (tagged on the page). Source files can move or disappear on the agency sites, which is why copies are kept in `raw/`. Prose notes on the page contain a few numbers typed in as text; the charts and labels come from `data/orcsd_years.json`.
